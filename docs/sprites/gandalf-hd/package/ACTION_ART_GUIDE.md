# Action art guide
The full board adds expressions, multiple facing studies, walk/run/book poses, fire release, cyan wards/channeling, hurt/collapse, and chest/loot interactions. The separate large key-pose sheet supplies four visual stages each for walk, projectile casting and spellbook use.

Use the original canonical board for identity; these new sheets expand pose vocabulary. Generated turnaround studies are not a validated eight-direction set. Do not label them as complete rotations without checking facing and camera angle.

For walk, retain feet pivot and rebuild alternating contact/passing poses; add in-betweens and test foot sliding. For casting, use anticipation → extension → release → recovery and keep the projectile separate. For spellbook, preserve book size and left supporting hand through opening/reading/page-turning. Use cropped effect studies as visual inspiration; they still contain their dark board background.

All included action art is reference artwork. It is not registered animation, clean pixel-grid output, or a finished sprite atlas. Generate and QA actual transparent frames in PixelLab using the supplied per-action prompts. Existing manifest remains needs-generation intentionally.

Observed QA: walking studies do not establish a clean alternating-leg cycle; casting studies need consistent casting-hand correction. Use these for silhouette and gesture, then author coherent frame continuity. Large sheet retains source semi-transparent haze and needs background cleanup before sprite use.
