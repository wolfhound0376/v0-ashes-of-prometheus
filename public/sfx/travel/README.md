# Road arrival cues (lib/travel/stingers.ts)

The seven sounds of a road arrival, all picked by Sam on the Road Cues Audition
page (2026-10-14). Runway: `lyria-3-clip` for the music stings, sound effects for
the short blips. Stings cut to 9 s with a 2 s fade at −16 LUFS; the short cues
trimmed and levelled to −18 LUFS. In-game levels live in `STINGER_GAIN`.

| file | take | what it is |
|---|---|---|
| quiet.mp3 | A | cello + harp arpeggio |
| discovery.mp3 | C | tremolo strings + flute, cymbal swell |
| hazard.mp3 | G | dissonant string cluster swelling out of silence, detuned piano, cut dead |
| nightfall.mp3 | A | low flute over strings, campfire crackle |
| great-place.mp3 | C | harp gliss → strings + timpani |
| noticed.mp3 | C | glassy three-note arpeggio + glint |
| missed.mp3 | G | one low cello note swelling and dying under an uneasy harmonic |

**Sam's ruling, 2026-10-14:** hazard and missed are *ominous horror* — "It should
be ominous horror type music". Rounds 1–2 were impact-led (brass stabs, taiko,
wooden knocks) and were rejected; dread that swells beats something that hits.
Missed is deliberately the quietest of the set: it plays on every failed passive
roll, so it suggests something still out there rather than startling anyone.

Nothing enters this folder without a pick on the audition page (the art rule).
A missing file is silence, never an error.
